# Obsidian Second Brain Guide

Companion index to the downloadable Word document **`Obsidian Second Brain Guide.docx`** (in this folder, and a copy in your Documents folder). The docx compiles everything from the Claude Code working sessions: what was set up, the workflow, the do/don't guidelines, and every recommended YouTube link.

## What's inside the Word doc

1. **What was set up in the vault** — cleanup, structure/links, imported past work, plugin inventory (Templates, Daily Notes, Dataview, PDF++, Git).
2. **The core workflow** — capture → literature note → permanent note → MOC → weekly review; plus the NotebookLM→Obsidian and PDF++ reading loops.
3. **The tagging & note-type system** — the six note types, status field, tags, sample Dataview queries.
4. **Guidelines — do & don't** — including what to do with old PPT/Word notes.
5. **Learning resources (YouTube)** — 14 verified links, grouped and in watch order.
6. **Suggested next actions.**
